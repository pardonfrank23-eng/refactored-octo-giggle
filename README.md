# Michelle & SpAwN – Website Grundgerüst

Eine moderne, deutsche Erotik-Memberseite mit 10 Bereichen, Foto- & Videogalerien und Abo-System.

## Struktur

```
site/
├── index.html   – komplette Seite (Start, Über uns, 10 Bereiche, Abos, Regeln & Bestellliste, Kontakt, Login)
├── style.css    – dunkles, hochwertiges Design
├── script.js    – Login-Modal & Navigation
└── img/         – hier kommen die Bilder rein (cover.jpg, Spawncover.jpg, Michellecover.jpg, ...)
```

## Bereiche (10)
1. Füße · 2. Achsel · 3. Po · 4. Brust · 5. Muschi · 6. Squatten · 7. Blasen · 8. Fotos · 9. & 10. offen (Namen folgen)

Jeder Bereich: Fotogalerie + Videogalerie, nur für zahlende Mitglieder sichtbar (lock icon 🔒).
